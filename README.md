# Mô tả
Hệ thống Quản lý Khách sạn được xây dựng nhằm cung cấp một nền tảng đơn giản, hiệu quả và hiện đại giúp khách sạn quản lý toàn diện các hoạt động như đặt phòng, quản lý khách hàng, quản lý phòng, xử lý đơn đặt và theo dõi trạng thái một cách chính xác và nhanh chóng.

# Giới thiệu dự án
Dự án Hệ thống Quản lý Khách sạn được xây dựng nhằm mô phỏng các nghiệp vụ cơ bản trong hoạt động quản lý khách sạn, bao gồm quản lý phòng, khách hàng và đơn đặt phòng. Hệ thống được phát triển bằng ngôn ngữ lập trình Python, giúp người học làm quen với tư duy lập trình, thiết kế chức năng và làm việc nhóm thông qua GitHub.
Dự án hướng đến việc tạo ra một phần mềm đơn giản, dễ sử dụng, phục vụ cho mục đích học tập và thực hành các kiến thức về phát triển phần mềm, quản lý mã nguồn và cộng tác nhóm.

# Mục tiêu dự án
Xây dựng một hệ thống quản lý khách sạn ở mức cơ bản bằng Python
Áp dụng kiến thức lập trình vào bài toán thực tế
Thực hành làm việc nhóm và quản lý source code trên GitHub
Rèn luyện kỹ năng phân chia công việc, review code theo mô hình Scrum
Hoàn thành một sản phẩm phần mềm có thể chạy và minh họa được các chức năng chính
